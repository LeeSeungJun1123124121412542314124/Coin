## 2. 화면에서 직접 본 것

- 리서치 "주식심리" 카드에 `F&G 25.2297455968689`처럼 소수가 그대로 나온다. (`services/research_analyzer.py:234`)
- 모바일 대시보드에서 큰 숫자가 중간에 줄바꿈된다: `$2.1 / 4T`, `23,879.1 / 99`.
- 지수 소수 자리가 제각각이다: NASDAQ 23,879.199(3자리), KOSPI 4,942.22(2자리), KOSDAQ 657.5(1자리).
- 리더보드 방향 칸의 `B E S` 배지(9.6px)는 무슨 뜻인지 설명이 없고, 모바일에서는 뒤쪽 열(vs매수보유·승률·MDD·Sharpe·거래)이 옆으로 밀려도 스크롤 표시가 없다.
- SPF "최근 예측 기록"의 7·14·30·60 판정 칸이 너무 작아 읽을 수 없다.
- 유동성 화면은 데이터가 없을 때 `$—B`, `$—T`, `알 수 없음`만 보이고 이유나 다시 시도 버튼이 없다.
- 학습 차트의 와이코프 표식이 스프링(상승 신호) 초록, 업스러스트(하락 신호) 빨강이라 화면 전체의 "빨강 상승·파랑 하락" 규칙과 반대다. (`learningChartData.ts:13-14`)
- SPF "반등 기대" 점수도 초록이다. (`SPF.tsx:169, 296`)

### 배치·밀도
- 대시보드 코인가격 띠가 PC에서 6+1로 줄바꿈돼 XRP만 혼자 다음 줄에 놓인다. ETH 카드만 H/L이 두 줄이라 높이가 다르다. KOSDAQ 카드, 시장분석의 지표 카드(4+2)도 같은 식으로 남는다.
- NASDAQ·KOSPI·KOSDAQ 카드 아래쪽이 점선 한 줄만 있고 비어 있다.
- 알림히스토리가 78건을 한 페이지에 다 펼친다(PC 8,700px, 모바일 12,600px). 위쪽 레벨 칩은 개수만 보여 주고 걸러 보기는 심볼만 된다.
- 12px보다 작은 글자가 많다: 대시보드 141곳, 볼륨 105곳, SPF 124곳, 알림 311곳(PC 기준, 사이드바 그룹명 5곳 포함).
- 모바일에서 누르기 작은 것: 코인가격 "편집" 23×26, 학습 종목 제거 × 17×22, 탭(코인/한국/미국) 높이 30, CVD 주기 버튼 43×29, 리서치 분류 칩 높이 30.
- 모바일에서 글자 16px 미만 입력칸: 학습 8곳, 알림 심볼 선택 1곳. 아이폰에서 누르면 화면이 확대된다.
- 이모지가 아직 남아 있다: SPF 안내문(🧭), 리더보드 안내문(💰), 시장분석 인사이트(📉 등), 리서치 위험 배지(🚨), 학습 백테스트 탭(🔬🔄🚀✅❌).

## 3. 사용 흐름
- PIN 화면: 틀렸을 때와 서버·네트워크 오류가 구분되지 않고 흔들리기만 한다. PC에서 키보드 숫자 입력이 안 된다. (`App.tsx:72-137`)
- 로그인 정보가 탭을 닫으면 사라져(`sessionStorage`) 폰에서 앱을 다시 열 때마다 PIN을 넣어야 한다. 토큰 자체는 24시간 유효하다.
- 로그인이 만료되면 안내 없이 새로고침되어 입력하던 내용이 사라진다. (`lib/api.ts:20-24`)
- 오류 문구가 `HTTP 400: indicators.macd.fast는 slow보다 작아야 합니다.`처럼 원문 그대로 나온다.
- 한 화면이 오류로 멈추면 다른 메뉴로 가도 오류 화면이 남는다(새로고침해야 풀림). (`ErrorBoundary.tsx`)
- 리더보드: "시드 리셋"이 브라우저 기본 확인창·알림창을 쓰고, 진행 중 표시가 없다. 상세 조회 실패가 "곡선 데이터 없음"으로 보인다. 새로고침·자동 갱신이 없다.
- 학습 차트는 한 번 불러온 뒤 자동 갱신이 없어 켜 두면 캔들이 낡는다.
- 학습 → 백테스트 탭의 표는 고정 폭이라 폰에서 열이 잘린다. (`AutoBacktest.tsx:246`, `CompositeSimulator.tsx:670`)
- 시간 기준이 화면마다 다르다: 알림은 KST, 학습 캔들은 UTC, 볼륨·리서치는 브라우저 시간, 대시보드 뉴스는 표기 없음.

## 4. 서버·운영 (나머지)
- 야후 파이낸스 폴백과 매크로 헬스 계산이 비동기 처리 안에서 동기로 돌아, 걸리면 서버 전체 응답이 몇 초 멈춘다. (`collectors/yahoo_finance.py:60-86`, `api/health_routes.py:18`)
- 시작할 때 SPF·1시간봉 수집을 끝까지 기다린 뒤 서비스가 열린다. 외부 API가 느리면 배포 직후 접속이 늦어진다. (`main.py:159-176`)
- 백테스트 튜닝(`/sim/tune`)에 동시 실행 제한이 없어 여러 번 누르면 컨테이너가 멈출 수 있다. 결과 파일도 쌓인다.
- 메모리 캐시에 크기 상한이 없다. (`cache.py`)
- SQLite `busy_timeout` 미설정.
- 없는 `/api/...` 주소가 404 대신 화면 HTML(200)을 돌려준다.
- 오류 응답 모양이 `{"error":…}`와 `{"detail":…}` 두 가지로 섞여 있다.
- Railway와 OCI가 동시에 돌고 있어 같은 텔레그램 방으로 알림이 두 번 갈 수 있다(같은 방을 쓰는지는 확인하지 않음).

## 5. 코드 정리
- 화면 파일이 한 덩어리(JS 1.0MB)로 묶여 첫 접속 때 11개 화면과 차트 라이브러리 2종을 모두 받는다. 화면별로 나눠 받게 할 수 있다.
- `index.css` 1,529줄 중 옛 메뉴·옛 시안용 CSS가 대략 700줄 남아 있다(클래스 140개 중 59개 미사용). `src/App.css` 184줄은 어디서도 불러오지 않는다.
- 숫자 표시 함수가 3곳 이상에서 따로 만들어져 서로 달라졌다(`Dashboard.tsx:195`, `learningShared.ts`, `lib/format.ts`).
- 대시보드 응답 조립에 같은 줄이 12번 반복된다(`api/dashboard_routes.py`).
- `.worktrees/feature/indicator-expansion/`에 프로젝트 전체 사본이 남아 있다.

## 6. 문제없던 것
- `/api/*`는 로그인·헬스 두 개를 빼고 모두 인증이 걸려 있다. SQL은 전부 파라미터 바인딩이다.
- 모든 외부 호출에 타임아웃이 있다. 정적 파일 경로 탈출 방지와 테스트가 있다.
- 자동 갱신은 탭이 숨겨지면 멈추고 돌아오면 바로 갱신한다. 요청 취소·정리도 된다.
- 모바일 하단 메뉴가 내용을 가리지 않는다. 더보기 시트의 키보드·포커스 처리가 갖춰져 있다.
- 11개 화면 모두 PC·모바일에서 페이지가 옆으로 넘치지 않는다.
- 하드코딩 색은 와이코프 표식 2개뿐이고 나머지는 토큰을 쓴다.
