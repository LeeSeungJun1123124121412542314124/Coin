# 학습 탭 보조 지표 추가 스펙

- 작성일: 2026-11-19
- 스펙 도구(ouroboros)가 이번 세션에서 연결되지 않아 사용자 결정을 이 문서에 직접 기록한다

## 1. 목표
학습 탭 차트에 이동평균선·볼린저밴드·거래량·RSI·MACD를 추가해, 일목·와이코프·엘리엇 말고 다른 지표도 필요할 때 켜서 볼 수 있게 한다.
> 사용자: "지표 설정 보면 다른 지표가 하나도 없어 가끔 다른 지표 보고 싶을때도 있는데"

## 2. 사용자 결정 (2026-11-19)
| 항목 | 결정 |
|---|---|
| 추가 지표 | 이동평균선, 볼린저밴드, 거래량, RSI·MACD |
| 설정 저장 | 서버(지금의 지표 설정처럼 `learning_settings`에 저장, PC·폰에서 같게) |

## 3. 지표 정의
| 지표 | 위치 | 기본값 | 바꿀 수 있는 값(범위) |
|---|---|---|---|
| 이동평균선 | 차트 위 겹침 | 꺼짐, 단순(SMA), 기간 5·20·60·120 | 종류 SMA/EMA, 기간 1~6개 각 2~400 정수 |
| 볼린저밴드 | 차트 위 겹침(상·중·하단 선) | 꺼짐, 20봉, 2표준편차 | 기간 5~200 정수, 표준편차 0.5~4 |
| 거래량 | 차트 아래 칸(막대) | 꺼짐 | 없음. 상승봉 `--up`, 하락봉 `--down` 반투명 |
| RSI | 차트 아래 칸(선, 70·30 기준선) | 꺼짐, 14 | 기간 2~100 정수 |
| MACD | 차트 아래 칸(MACD선·시그널선·히스토그램) | 꺼짐, 12·26·9 | 빠른 2~200, 느린 3~400(빠른 < 느린), 시그널 2~100 정수 |
- 계산: 이동평균 SMA = 단순 평균, EMA = α 2/(n+1)이고 첫 값은 첫 n봉 SMA. 볼린저 = n봉 SMA ± k × 모표준편차. RSI = 와일더 평활(첫 값은 n봉 평균 상승·하락). MACD = EMA(빠른) − EMA(느린), 시그널 = MACD의 EMA(시그널), 히스토그램 = MACD − 시그널
- 값이 정의되지 않는 앞부분 봉은 결과에서 뺀다(빈 점 없이 정의된 봉부터)
- 서버가 계산한다(일목처럼). 차트 API는 보이는 봉 수 + 워밍업을 읽는데, 워밍업 = max(52, 가장 긴 이동평균 기간, 볼린저 기간, RSI 기간 × 3, (MACD 느린 + 시그널) × 3), 상한 1500
- 색: 이동평균 기간 순서대로 `C.accent`·`C.info`·`C.violet`·`C.warn`·`C.ok`·`C.text2`, 볼린저 상·하단 `C.text2`·중단 `C.text3` 점선, RSI 선 `C.violet`·70 `C.warn`·30 `C.ok` 점선, MACD선 `C.info`·시그널 `C.warn`·히스토그램 양수 `C.up`·음수 `C.down` 반투명. 상승/하락 뜻인 곳만 up/down

## 4. 화면
- 차트 위 지표 칩 줄에 `이동평균`·`볼린저`·`거래량`·`RSI`·`MACD` 칩을 기존 칩(일목·지그재그·피보) 뒤에 추가. 칩을 누르면 서버 설정의 `enabled`가 바뀌고 저장된다(실패하면 원래 상태로 돌리고 오류 표시)
- "지표 설정" 폼에 이동평균 종류·기간(쉼표 구분), 볼린저 기간·표준편차, RSI 기간, MACD 세 값 입력칸 추가. 범위 밖이면 서버 400 메시지를 지금처럼 보여 준다
- 아래 칸(거래량·RSI·MACD)은 켜진 것마다 차트 아래에 쌓이고, 칸이 하나 늘 때마다 차트 전체 높이가 늘어난다(본 칸 높이는 그대로). 시간축·십자선은 모든 칸이 공유

## 5. 완료 기준
| # | 기준 | 검증 |
|---|---|---|
| 1 | 설정 기본값·범위 검증(정수·범위·빠른 < 느린·기간 개수), 예전에 저장된 설정에도 기본값이 채워진다 | pytest |
| 2 | SMA·EMA·볼린저·RSI·MACD 값이 손으로 계산한 기준값과 맞고, 정의 안 되는 앞부분은 빠진다 | pytest |
| 3 | 차트 API가 켜진 지표만 `indicators`로 돌려주고, 워밍업 덕분에 보이는 첫 봉부터 값이 있다(데이터가 충분할 때) | pytest |
| 4 | 칩으로 켜고 끄기와 설정 폼 저장이 서버에 반영되고 새로고침해도 유지된다 | 화면 확인 |
| 5 | 아래 칸이 쌓이고 십자선·시간축이 함께 움직인다 | 화면 확인 |
| 6 | 기존 테스트 전부 통과, ruff·eslint 새 문제 없음, 빌드 통과 | 명령 실행 |

## 6. 제약
- 새 패키지 금지(lightweight-charts 5의 pane 기능 사용), 유료 API 없음, DB 스키마 변경 없음(설정은 기존 key-JSON 테이블)
- 기존 지표(일목·와이코프·엘리엇)와 매매·복기 동작은 바뀌지 않는다
- push는 사용자 승인 후
