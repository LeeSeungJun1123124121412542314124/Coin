## 대체 소스 검증 (운영 DB 확정일 값과 대조)

| 데이터 | 새 소스 | 대조 결과 |
|---|---|---|
| 시장 투자자 수급 | `m.stock.naver.com/api/index/{KOSPI\|KOSDAQ}/trend?bizdate=YYYYMMDD` | 기존 값과 **완전 일치** (09-10~16 전 항목) |
| 시장 거래대금 | `finance.daum.net/api/market_index/days?market=..&page=1&perPage=N&pagination=true` | `accTradePrice`(백만원)/1e6 = 기존 조원 값 **소수점 4자리 완전 일치** |
| 거래일 목록 | `m.stock.naver.com/api/index/{market}/price?pageSize=N&page=1` 의 `localTradedAt` | 휴장일(10-09) 제외 확인 |

- 다음 금융 투자자 수급은 일부 날짜 불일치 → **수급은 네이버, 거래대금은 다음**으로 분리.
- 네이버 모바일 `integration`의 거래대금은 약 6% 차이 → 사용 안 함.
- **함정**: `trend`에 휴장일·주말 bizdate를 넣으면 에러가 아니라 `0/0/0`을 반환 → 반드시 `price` 거래일만 요청.
- 다음 API는 `Referer: https://finance.daum.net/...` 헤더 필요.
- 17:30 KST 수집값은 비확정(09-17 DB 값이 두 소스 확정값과 불일치) → 재수집 덮어쓰기 필요.

## 확정 결정 (사용자 2026-11-18)

- **D1 공백 백필**: 잡이 스스로 채움. 수집 창 = `min(60, max(30, DB 마지막 날짜 이후 평일 수))` 영업일.
  첫 배포 실행이 09-18~ 공백(약 43영업일)을 백필하고, 이후 끊겨도 60영업일 내 자동 복구.
- **D2 재수집 구간**: 매 실행 최근 30영업일 덮어쓰기(기존과 동일). upsert 3종 모두 `ON CONFLICT DO UPDATE` 확인.
- **D3 13F 판별 규칙**: filing 루트의 `.xml` 중 `primary_doc.xml`이 아닌 것이 **정확히 1개**면 그것. 0개/2개 이상이면 ValueError(후보 목록 포함).
  근거: 실측 21개 공시(13F-HR, 13F-HR/A) 전부 해당 조건 충족.
- **D4 13F 실패 정책**: 판별·다운로드 실패한 공시는 건너뛰고 나머지 공시·기관은 계속 저장. 루프 종료 후 실패가 있으면 예외 → 기존 `async_retry` 재시도·잡 실패 알림. 성공 공시는 `known` 처리돼 재시도 때 중복 수집 안 함.
- **D5 검증**: 실제 응답 형식 픽스처 단위 테스트 + 로컬에서 실제 API로 임시 DB에 잡 1회 실행 + 배포 후 정기 실행 Railway 로그 확인.

## 설계

### 한국 수급 (`collectors/naver_finance.py`, 신규 `collectors/daum_finance.py`, `jobs/collect_kr_stock.py`)

- `fetch_investor_deal_trend(market, days)` — **시그니처 유지, 내부 교체**:
  `price?pageSize=days`로 거래일 목록 → 날짜별 `trend?bizdate=` 호출 → 응답 `bizdate`가 요청과 다르면 스킵.
  `"+4,331"` → `4331.0`(억원). 상한 30 → 60.
- `fetch_market_volume(market, days)` — 다음 금융으로 교체, 신규 `daum_finance.py`로 이동.
  `round(accTradePrice / 1_000_000, 4)` 조원.
- `fetch_stock_investor_trend(code, days)` — 상한 30 → 60 (API가 `page`는 무시하고 `pageSize=60`은 08-20까지 반환 확인).
- 잡: 시작 시 `kr_investor_flow` 최대 날짜로 창 계산(D1) → 세 fetch에 같은 `days` 전달. 실패 시 raise 동작은 유지.
- 고아 정리: `parse_investor_flow_html`, `parse_market_volume_html`, `_TableRowParser` 등 PC 페이지 전용 코드와 그 테스트 제거.

### 13F (`collectors/edgar.py`, `jobs/collect_us_13f.py`)

- `parse_filing_index` 규칙을 D3으로 교체.
- 잡의 filing 처리 블록을 공시 단위 try/except로 감싸 실패 수집(D4), 루프 후 실패 있으면 RuntimeError(실패 accession 목록).
