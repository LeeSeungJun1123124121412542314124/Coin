## 3. 서비스 워커 규칙 (`sw.js`, 캐시 이름 `coin-shell-v1`)

- 화면 이동(HTML): **네트워크 우선**. 연결이 안 되거나 서버 오류(5xx)면 캐시해 둔 첫 화면.
- `/assets/*`(빌드 해시 파일)·`/icons/*`: 캐시 우선. `/assets/` 항목은 80개까지만 남긴다.
- `/api/*`와 다른 출처(글꼴 등)는 건드리지 않는다 — **시세·분석 값은 캐시하지 않는다**.
- GET이 아닌 요청은 건드리지 않는다.
- 없앨 때는 파일을 지우지 말고 "등록 해제 + 캐시 삭제"만 하는 `sw.js`를 같은 주소에 배포해야 한다.

## 4. 바뀌지 않는 것

- PIN 로그인과 API 인증은 그대로다. 로그인 토큰이 `sessionStorage`에 있어서, 설치한 앱도 창을 새로 열 때마다 PIN을 다시 묻는다.
- 연결이 끊기면 첫 화면(껍데기)은 뜨지만 데이터는 나오지 않는다. 오프라인 사용은 범위 밖이다.
