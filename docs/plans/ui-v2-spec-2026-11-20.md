## 3. 대시보드 "시장 분위기 한 줄" 규칙
근거 4개를 각각 한 가지 표로 바꾼다.
| 근거 | 데이터 | 표 |
|---|---|---|
| BTC 국면 | 학습 일봉 차트의 일목 4개 상태(`summarizeBtcPhase`의 `states`) | 하락 상태 3개 이상 → `down`, 상승 상태 3개 이상 → `up`, 그 외 → `flat`. 데이터 없음 → 근거에서 뺀다 |
| SPF 중기 전망 | `/api/spf-data`의 `today_prediction.direction`·`confidence` | 하락 → `down`, 상승 → `up`, 중립·없음 → `flat` |
| 주의 신호 | `/api/market-analysis`의 `insights` 중 `level`이 `warning`·`critical`인 것 | 1건 이상 → `caution`, 0건 → `flat` |
| 공포탐욕 | `/api/dashboard`의 `fear_greed.value` | 25 이하 → `rebound`(반등 신호), 75 이상 → `caution`(과열 주의), 그 외 → `flat` |

판정(위에서부터 먼저 맞는 것):
1. `down` 2개 이상 → 표시 "주의"(`--warn`), 머리말 "조심할 구간"
2. `up` 2개 이상이고 `down` 0개 → 표시 "우호"(`--ok`), 머리말 "우호적인 구간"
3. 그 외 → 표시 "혼조"(회색), 머리말 "방향이 엇갈립니다"

문장 = `머리말 — 꼬리말`. 꼬리말은 표가 `flat`이 아닌 근거를 근거 순서(BTC 국면 → SPF → 주의 신호 → 공포탐욕)대로 최대 2개 골라 짧은 구절로 잇는다: BTC `down` "하락 추세", `up` "상승 추세" / SPF `down` "중기 전망 하락", `up` "중기 전망 상승" / 주의 신호 "주의 신호 N건" / 공포탐욕 `rebound` "극단적 공포", `caution` "과열 구간". 구절이 없으면 꼬리말 없이 머리말만 쓴다. 집계 줄은 0이 아닌 것만 "하락 2 · 주의 1 · 반등 1"처럼 적는다(상승은 "상승 N").
근거 4개 중 데이터가 온 것이 2개 미만이면 판정을 내지 않고 "근거를 불러오는 중입니다"와 받은 근거만 보여 준다.

## 6. 제약
- 색·글꼴·사이드바·하단 메뉴 구조는 바꾸지 않는다. 색은 토큰(`var(--…)`, `C.*`)만
- 새 패키지 금지, API 응답 구조 변경 금지. 백엔드 변경은 리서치 요약 문자열의 숫자 자리 하나(`research_analyzer.py`)와 이모지 아이콘 문자열 교체까지만
- 요청 범위 밖 리팩터링 금지. 구조를 단언하는 Python 테스트는 새 구조에 맞게 같은 커밋에서 고친다
- 주석·커밋 한국어, master 로컬 커밋, push는 사용자 승인 후
