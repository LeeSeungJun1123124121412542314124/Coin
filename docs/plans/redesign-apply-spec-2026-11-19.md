## 1. 목표
투자분석기 프론트 11개 화면(대시보드, 볼륨트래커, SPF, 리서치, 시장분석, 유동성, CVD 스크리너, 고래추적, 리더보드, 알림히스토리, 학습)을 시안의 "고급 다크" 디자인으로 바꾼다. 사용자 요청: "전체적인 디자인 진짜 구린데 … 좀 세련되고 UI도 좀 보기 편했으면".

## 4. 글자·배치
- 글꼴: 본문 `IBM Plex Sans KR` 400/500/600/700, 숫자 `IBM Plex Mono` 400/500/600(가격·수량·비율·시각·점수)
- 크기: 페이지 제목 30/700 자간 -0.03em, 섹션 제목 18/600, 카드 제목 15/600(KPI 카드 라벨 14/600 `--text-2`), 본문·행 14, 캡션 12, KPI 숫자 Mono 30/600, 히어로 숫자 Mono 40/600
- 셸: 왼쪽 사이드바 232px(브랜드 + 그룹 메뉴), 본문 여백 `32px 40px 56px`, 카드 간격 20px. 페이지 머리: 위치(그룹 / 탭) 13px `--text-3` → 제목 → 설명 14px `--text-2`, 오른쪽에 최종 갱신·자산 탭 같은 조작
- 사이드바 그룹: 개요(대시보드) / 시장(시장분석·유동성·볼륨트래커) / 파생 · 온체인(SPF·CVD 스크리너·고래추적) / 기록 · 검증(리서치·리더보드·알림히스토리) / 학습(학습). 활성 항목은 `--accent` 글자 + accent 12% 바탕, 높이 40px
- 모바일(768px 미만): 사이드바 숨김, 하단 메뉴 5칸 홈·시장·파생·학습·더보기. "더보기"는 나머지 화면 목록을 여는 시트. 터치 영역 44px 이상
- 접근성: 버튼은 `<button>`, 탭은 role=tab/aria-selected, 아이콘만 있는 버튼은 aria-label, 본문 대비 4.5:1 이상(토큰 값은 이 기준을 맞춘 값)

## 5. 시안에만 있던 기능 (이번에 구현)
1. **대시보드 "BTC 시장 국면" 카드**: `GET /api/learning/chart?symbol=BTCUSDT&interval=1d&limit=90`로 마지막 마감 일봉 종가, 전일 대비 %, 90일 고저 범위, 90일 종가 스파크라인, 일목 상태 4개(구름 위치·전환·기준선·후행스팬·미래 구름)를 보여 준다. BTCUSDT를 추적하지 않아 404면 "학습 탭에서 BTCUSDT를 추가하면 표시됩니다" + 학습 탭 링크. 백엔드 변경 없음
2. **학습 탭 가격축 선형/로그 토글**: 차트 위 세그먼트 [선형 | 로그], 기본 선형, lightweight-charts 가격축 모드 전환. 상태는 화면 안에서만 유지
3. **유동성 "응찰률" 표기**: 최근 경매 결과의 `BTC N.NNx`(bid-to-cover)를 `응찰률 N.NNx`로
4. **알림히스토리 날짜별 묶음 + 레벨 건수 요약**: 불러온 알림을 KST 날짜별로 묶어 "오늘 / 어제 / MM-DD" 머리글 아래 표시, 맨 위에 레벨 6종(확인 경보·경보·청산 위험·고래 감지·갱신 필요·매크로 이벤트)별 건수 칩. 심볼 필터 적용 뒤 기준
5. **모바일 하단 5칸 + 더보기 시트**(4절)

## 6. 화면별 요구 (시안 보드 기준, 기존 데이터·동작은 유지)
- 공통: 자산 탭(코인/한국/미국·환율)은 세그먼트 컨트롤, 로딩 Skeleton·오류 ErrorState도 새 토큰으로
- 대시보드(Main): 시세 띠 → BTC 국면 카드 + 오른쪽 KPI 카드들 → "시장 메인 카드" 6개(행 라벨·Mono 값·▲▼ 변화) → 뉴스·기타 기존 섹션
- 학습(Learning): 종목 칩 → 시간봉 세그먼트·지표 토글 칩·선형/로그·지표 설정 → 차트 카드 + 오른쪽 일목 상태·모의 주문 → 일지/복기/성과/백테스트 탭
- 시장분석·유동성·볼륨트래커·SPF·CVD·고래추적·리서치·리더보드·알림히스토리: 각 시안 보드의 카드 구성·배지 색 규칙을 따른다(배너는 의미 색 7% 바탕 + 28% 테두리, 점수 막대 6~8px 트랙)
- 색 규칙: 롱·매수·상승·급등·강세 = `--up`, 숏·매도·하락·급락·약세 = `--down`, 하락위험·주의·경계 = `--warn`, 반등기대·정상·공급·적중 = `--ok`, 위험·확인 경보 = `--danger`

## 8. 제약
- 새 npm 패키지 설치 금지(글꼴은 Google Fonts 링크)
- 백엔드 API·데이터 변경 없음
- 기존 기능(데이터 표시, 조작, 라우팅 경로) 유지. 화면 구조를 바꿔도 같은 정보는 남긴다
- 외과적 변경 원칙: 시안과 무관한 로직 리팩터링 금지
- push는 사용자 승인 후
