# HTF-LTF 방향 점수 + 매매 제안 스펙 (2026-11-24)

학습 화면에 "상위·하위 시간봉 구조 점수"와 "Entry A/B·손절·익절 제안"을 추가한다.
규칙 근거는 `docs/htf-ltf-rules-from-ysdent-2026-11-24.md`(이하 "규칙 문서")이다.
규칙 문서에 없는 부분은 이 스펙에서 **우리가 정한 값**이며, 각 항목에 그렇게 표시한다.

## 1. 목표와 범위

- 목표: 종목·시간봉을 고르면 구조 점수(0~100, 50 중립, 높을수록 매수)와 그 근거, 그리고 점수가 한쪽으로 기울었을 때 매매 제안(Entry A 30%·Entry B 70%·손절·Risk Free·TP1·TP2·손익비)을 보여 준다.
- 범위 밖:
  - 와이코프·일목 등을 합친 종합 점수(보조 확인으로 표시만 한다).
  - 15분봉 등 새 시간봉 수집.
  - 모의 주문에 손절·익절 저장, 지정가·미체결 주문(현재 주문은 현재가 즉시 체결만 있다).
  - 알림, 점수의 과거 성과 검증(백테스트).

## 2. 구조 판정 규칙 (규칙 문서 A·B절 그대로)

순수 함수로 `dashboard/backend/services/learning_structure.py`에 둔다(DB·네트워크 없음, 입력은 캔들 dict 리스트).

1. **스윙**
   - 단기 고점: 가운데 봉의 고가가 양옆 봉의 고가보다 높다. 단기 저점은 대칭.
   - 중기 고점: 단기 고점들만 늘어놓았을 때 가운데가 양옆보다 높은 것. 저점은 대칭.
   - 장기 고점: 중기 고점들에 같은 규칙. 저점은 대칭.
   - 같은 값은 스윙으로 치지 않는다(**우리가 정한 값**, 글에 없음).
   - 스윙은 오른쪽 봉이 마감된 뒤에야 확정된다(미래를 미리 보지 않는다).
2. **구조 돌파(MSB)**
   - 종가가 아직 안 깨진 가장 최근 중기 고점을 넘으면 상승 돌파(약), 장기 고점을 넘으면 상승 돌파(강). 하락은 대칭.
   - 꼬리만 넘은 것은 돌파가 아니다.
   - 직전 돌파와 같은 방향이면 지속(BoS), 반대 방향이면 전환(CHoCH).
3. **시간봉별 구조 상태**
   - `trend`: 마지막 돌파의 방향(`up`/`down`), 돌파가 한 번도 없으면 `neutral`.
   - `last_break`: `{time, level, direction, kind(bos|choch), strength(weak|strong), bars_ago}`.
   - `fresh`: `bars_ago <= 20`(규칙 문서의 "20캔들 경과 시 신선도 저하").
   - 캔들이 60개 미만이면 `insufficient`(**우리가 정한 값**)로 보고 `neutral` 취급.

## 3. 시간봉 조합

| 보고 있는 시간봉(LTF) | 상위 시간봉(HTF) | 근거 |
|---|---|---|
| 1시간봉 | 일봉 | 규칙 문서 예시 |
| 4시간봉 | 일봉 | 규칙 문서 예시 |
| 일봉 | 주봉 | 우리가 정한 값 |
| 주봉 | 월봉 | 우리가 정한 값 |
| 월봉 | 없음(HTF 중립 처리) | 우리가 정한 값 |

## 4. 점수 환산 (우리가 정한 값)

`점수 = 50 + HTF 기여 + LTF 기여 + 일치 가산`, 0~100으로 자른다.

| 항목 | 조건 | 점수 |
|---|---|---|
| HTF 기여 | 상승·신선 / 하락·신선 | +20 / −20 |
| | 상승·오래됨 / 하락·오래됨 | +5 / −5 |
| | 중립·자료 부족 | 0 |
| LTF 기여 | 상승·신선 / 하락·신선 | +20 / −20 |
| | 상승·오래됨 / 하락·오래됨 | +10 / −10 |
| | 중립·자료 부족 | 0 |
| 일치 가산 | HTF·LTF 같은 방향이고 둘 다 신선 | 상승 +10 / 하락 −10 |

- 규칙 문서의 예시 2건과 맞춘 값이다: HTF 상승(오래됨)+LTF 하락 전환 → 50+5−20 = **35**, HTF 중립+LTF 상승 전환 → 50+0+20 = **70**.
- 표본이 2건뿐이라 이 식의 성과 근거는 없다. 화면에 "우리 규칙으로 계산한 점수"임을 적는다.
- 해석: 40 이하 매도 우위, 41~64 중립, 65 이상 매수 우위(65 이상 해석은 **우리가 정한 값**).
- 근거 문장(`reasons`)을 함께 만든다. 예: "일봉: 상승 구조, 마지막 돌파 23봉 전(오래됨) +5", "4시간봉: 하락 전환(CHoCH, 약) 3봉 전 −20".

## 5. 보조 확인 (점수에 넣지 않음)

구조 점수의 방향과 같은지 다른지만 표시한다.
- 일목 상태: 구름 위치·전환/기준선(기존 `state`).
- 와이코프: 최근 5봉 안의 스프링(매수 쪽)·업스러스트(매도 쪽)(기존 `wyckoff.candidates`).

## 6. 매매 제안

점수가 65 이상이면 롱, 40 이하이면 숏 제안을 만든다. 41~64는 "관망"이고 제안을 만들지 않는다.
모의 주문은 현물 매수·매도뿐이므로 숏 제안은 "참고"로 표시한다. 아래는 롱 기준이고 숏은 대칭이다.

| 항목 | 규칙 | 근거 |
|---|---|---|
| 손절(SL) | 현재가 아래 LTF 중기 저점(구조 무효화 지점) 중, 현재가에서 ATR(14) 1배 이상 떨어진 것 가운데 가장 가까운 것. 너무 가까운 스윙은 건너뛴다 | 규칙 문서 F절 + 최소 거리는 우리가 정한 값(실제 캔들에서 손절 폭 0.45%·손익비 28 같은 값이 나와 추가) |
| Entry A (30%) | 현재가(마지막 종가) | 규칙 문서 F절 |
| Entry B (70%) | 마지막 상승 돌파 레벨이 손절과 현재가 사이에 있으면 그 레벨(돌파 뒤 지지 전환), 아니면 손절 저점과 최근 고점의 0.5 되돌림 | 앞은 규칙 문서 B절, 뒤는 우리가 정한 값 |
| 평균 진입가 | A×0.3 + B×0.7 | 규칙 문서 F절 |
| 1R | 평균 진입가 − 손절 | 규칙 문서 F절 |
| 저항 후보 | 현재가 위의 안 깨진 스윙 고점(LTF 중기, HTF 단기·중기)을 가까운 순으로 | 우리가 정한 값 |
| Risk Free | 저항 후보 1번째(없으면 평균 진입가 + 1R). 도달 시 손절을 진입가로 옮기는 기준 | 규칙 문서 F절 |
| TP1 | 저항 후보 2번째(없으면 평균 진입가 + 2R) | 규칙 문서 F절 + 우리가 정한 값 |
| TP2 | 저항 후보 3번째(없으면 평균 진입가 + 3R). HTF가 중립이면 생략 | 규칙 문서 F절(생략 사례) |
| 손익비 | (TP1 − 평균 진입가) ÷ 1R | 규칙 문서 F절 |

경고 표시:
- 손익비가 1 미만이면 "손익비 부족 — 진입 비권장".
- 손절 폭이 평균 진입가의 10%를 넘으면 "손절 폭 큼".
- 손절로 쓸 스윙이 없으면 제안을 만들지 않고 이유를 적는다.
- Entry B가 현재가와 같으면(되돌림 구간이 없으면) "되돌림 진입 구간 없음 — Entry B가 현재가와 같음".
- ATR(14)은 최근 14봉의 True Range 단순 평균이다(우리가 정한 값).

## 7. API

`GET /api/learning/chart` 응답에 `structure` 필드를 추가한다(기존 필드는 그대로).
HTF 캔들은 같은 요청 안에서 `_load_candles(symbol, htf, 500)`로 읽는다.

```json
{
  "structure": {
    "htf_interval": "1d",
    "htf": {"trend": "up", "fresh": false, "insufficient": false, "last_break": {"time": 0, "level": 0, "direction": "up", "kind": "bos", "strength": "strong", "bars_ago": 23}},
    "ltf": {"trend": "down", "fresh": true, "insufficient": false, "last_break": {}},
    "score": 35,
    "label": "bearish",
    "reasons": ["..."],
    "checks": {"ichimoku": "agree", "wyckoff": "none"},
    "plan": {"side": "short", "entry_a": 0, "entry_b": 0, "avg_entry": 0, "stop": 0, "risk_free": 0, "tp1": 0, "tp2": null, "rr": 0, "warnings": []}
  }
}
```

- 캔들이 없으면 `structure`는 `null`.
- `plan`은 관망이거나 만들 수 없으면 `null`(이유는 `reasons`에).

## 8. 화면

- 오른쪽 열 "일목 상태" 카드 아래에 "구조 점수" 카드를 추가한다.
  - 점수와 해석(매수 우위·중립·매도 우위), 상위·하위 시간봉 각각의 상태 한 줄, 근거 문장 목록, 보조 확인.
  - 제안이 있으면 표(Entry A 30%, Entry B 70%, 평균 진입가, 손절, Risk Free, TP1, TP2, 손익비)와 경고.
  - 카드 아래에 "우리 규칙으로 계산한 참고 값이며 투자 권유가 아님" 안내.
- 차트 위 버튼 줄에 "매매 제안" 칩을 추가한다(기본 켜짐). 켜면 제안 가격을 가로선으로 그린다. 기존 피보나치 가격선과 같은 방식.
- 모의 주문 패널은 바꾸지 않는다.

## 9. 테스트 (성공 기준)

백엔드 `dashboard/tests/test_learning_structure.py`:
1. 3봉 규칙으로 단기 스윙, 단기 3개로 중기, 중기 3개로 장기가 잡힌다.
2. 종가가 중기 고점을 넘으면 약한 상승 돌파, 꼬리만 넘으면 돌파가 아니다. 장기 고점 종가 돌파는 강한 돌파.
3. 같은 방향 연속 돌파는 BoS, 반대 방향은 CHoCH.
4. 점수: HTF 상승(오래됨)+LTF 하락(신선) = 35, HTF 중립+LTF 상승(신선) = 70, 둘 다 상승·신선 = 100, 둘 다 중립 = 50.
5. 롱 제안: 손절 < Entry B ≤ Entry A < Risk Free < TP1 순서, 평균 진입가와 손익비 계산이 식과 일치.
6. 숏 제안이 대칭. 41~64는 제안 없음. 손익비 1 미만이면 경고.
7. 캔들 60개 미만은 `insufficient`.

API `test_learning_chart_api.py`: 응답에 `structure`가 있고, 1시간봉 요청 시 일봉을 HTF로 쓴다. 캔들이 없으면 `null`.

프론트: 타입·린트·빌드 통과, 기존 `npm test` 통과. 표시용 계산 로직이 생기면 `tests/`에 테스트를 추가한다.

화면 확인: 로컬에서 종목·시간봉을 바꿔 가며 카드와 가격선이 API 값과 일치하는지 본다.

## 10. 알려진 한계

- 점수 식은 예시 2건에 맞춘 것이라 실제 성과는 검증되지 않았다.
- 저쪽 사이트는 AI가 판단을 덧붙이는 방식이라 같은 차트에서도 점수가 다를 수 있다.
- 15분봉이 없어 가장 짧은 조합은 1시간봉+일봉이다.

## 11. 변경 — 과거 데이터 검증 후 축소 (2026-11-24)

`docs/plans/htf-ltf-backtest-2026-11-24.md`에서 점수의 방향 예측력과 매매 제안의 성과가 확인되지 않았다.
사용자 결정으로 **매매 제안을 빼고, 점수와 구조 가격 범위만 차트에 표시**한다. 위 5·6절과 8절의 카드·"매매 제안" 칩은 폐기한다.

- 제거: 매매 제안(`plan`), 보조 확인(`checks`), 구조 점수 카드, "매매 제안" 칩과 제안 가로선, 관련 코드·테스트.
- 응답 `structure`(7절 대체):
  - `htf_interval`, `htf`, `ltf`, `score`, `label`, `reasons`는 그대로.
  - `htf_pts`, `ltf_pts`, `bonus` 추가: 4절 점수표의 각 기여 점수(정수, 부호 포함).
  - `htf`·`ltf` 각각에 `range: {high, low}` 추가. `high`는 마지막 봉 시점에 확정돼 있고 아직 종가로 안 깨진 가장 최근 중기 고점, `low`는 같은 조건의 중기 저점이다(돌파 판정에 쓰는 바로 그 레벨). 없으면 `null`. 자료 부족이면 둘 다 `null`.
- 화면:
  - 차트 왼쪽 위에 한 줄: `HTF(일봉) +20 · LTF(4시간봉) −10 · 합계 60 중립`. 일치 가산이 있으면 `· 일치 +10`을 덧붙인다. 상위 시간봉이 없으면 `HTF 없음 0`. 마우스를 올리면 `reasons`가 보인다.
  - 가로선 4개: "HTF 고점", "HTF 저점", "LTF 고점", "LTF 저점"(값이 없는 것은 그리지 않음). HTF와 LTF는 색으로 구분한다.
  - 버튼 줄의 "구조 범위" 칩(기본 켜짐)으로 한 줄 표시와 가로선을 함께 켜고 끈다.
- 테스트: 범위 레벨이 돌파 판정에 쓰는 레벨과 같은지, 돌파 뒤 깨진 레벨이 범위에서 빠지는지, 기여 점수 합이 `score`와 맞는지(0~100으로 잘리는 경우 제외), 자료 부족 시 `null`.
